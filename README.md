# SellDevices

Telegram Mini App: экономическая игра о покупке, восстановлении и продаже устройств. Все рубли и акции — игровые.

## Запуск

`npm install` затем `npm start`. Откройте `http://localhost:3000`. В браузере запускается отдельный демонстрационный профиль. При наличии `DATABASE_URL` прогресс хранится в PostgreSQL; в локальной разработке без базы он хранится в памяти до остановки сервера.

Для Telegram создайте бота через BotFather, добавьте `TELEGRAM_BOT_TOKEN` в переменные окружения Render и укажите адрес опубликованного сайта как URL Mini App. Сервер проверяет подпись Telegram `initData`; данные браузерной демонстрации изолированы от Telegram-профиля.

## Размещение

`render.yaml` описывает веб-сервис. Для постоянного прогресса подключите отдельную PostgreSQL базу через `DATABASE_URL` и настройте резервное копирование. Не публикуйте токен бота в репозитории. Пока база не подключена, размещённый сайт работает как демонстрация, а прогресс может исчезнуть при перезапуске сервиса.
